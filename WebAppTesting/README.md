# Automated testing for WebApp

Uses the Selenium Python lean test architecture by [eliasnogueira](https://github.com/eliasnogueira/selenium-java-lean-test-architecture).

Used by Rye to exercise automated testing skills in Java Selenium.

To install, execute `pip install -e .` in this directory.

To build, execute `python -m build .` in this directory.

To run, execute `pytest --cov=mypackage --cov-report=term-missing` in this directory.
