# Automated testing for WebApp

Used to exercise automated testing skills in Python with Selenium.

* To install, execute `uv sync` in this directory.
* To run, execute `uv run pytest --cov=web_app_testing --cov-report=term-missing` in this directory.
* To contribute, use [VSCodium](https://vscodium.com/#install) and install the [Python](https://open-vsx.org/vscode/item?itemName=ms-python.python) and [Python Debugger](https://open-vsx.org/vscode/item?itemName=ms-python.debugpy) extensions.
